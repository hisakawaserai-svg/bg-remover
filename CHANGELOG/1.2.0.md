## 変更の記録

### 新機能

- 被写体検出による背景除去を追加。iOS 17以降は Vision、Android は ML Kit（公式下限 API 24 = Android 7.0。アプリ minSdk と同じなので入れた人は使える）。iOS 16以下ではカードは残すが選べず、毎回確認はオフ表示のまま無効（保存値は書き換えない）。スポイト・復元ブラシ・再透過・セル単位の調整は方式によらず常に色ベースのまま (a1bd795)
- iOS 17以降では、画像選択直後に背景除去の方式を確認するように。設定「画像を選ぶたびに確認する」でOFFにすると聞かずに固定できる。分割画面のヘッダーからも方式を変えてやり直せる (a1bd795)
- 復元ブラシに「消しゴム」トグルを追加。同じストローク記録の仕組みを共有し、なぞった範囲を色に関係なく透過できるように（スポイトが届かない孤立した消し残しの救済） (a1bd795)

### 改善

- 方式の確認を ActionSheet から、アイコン＋「選ぶと何が起きるか」を書いた縦積みカード（`BgEngineChoiceModal`）に変更。設定の方式選択も同じカードに揃え、違いが文面だけで判断できるようにした (e930304)
- Vision失敗時に生のネイティブエラーメッセージを表示する代わりに「色ベースで試す」選択肢を提示するように (a1bd795)
- 分割結果一覧(ResultScreen)に、背景色（白/黒/市松）切替と番号バッジの表示/非表示切替を追加。透過し忘れ・変な模様が残っていないかを確認しやすく (583e39c)
- 分割確認画面(SetupScreen)のヘッダーを整理。「戻る」と「ホーム」が同じ動作だったため、ホームアイコンを削除して「戻る」ラベルを「ホーム」に統合し、✨(方式変更)ボタン追加分のスペースを確保 (583e39c)
- PolygonEditor/ResultScreenの背景色ピッカーを、選んでも閉じないように変更（連続して見比べやすく。閉じるのはアイコンの再タップ） (583e39c)
- 復元ブラシ/消しゴムの見出し・説明・アイコンを、選んでいるモードに応じて出し分けるように（「戻す」中は復元ブラシの説明、「消しゴム」中は専用の説明とアイコン）。SetupScreenのツール予告一覧にも消しゴムの行を追加。MaterialCommunityIconsフォントを新たに同梱し、本物の消しゴムアイコンを使用 (e056332)
- 復元ブラシの中に隠れた消しゴムに気づきやすくするため、未使用の間だけ出るNEWバッジを追加（ツール切り替えメニュー・現在のツールボタン・トグル本体の3箇所。一度触れば消える） (63d33f3)
- 「範囲を調整」に「候補から選ぶ」を追加。未囲みの塊を黄枠で示し、選んだ分だけ緑にしてからまとめて四角を置く。判定はタップ置きと同じ splitConnected（色は見ない。触れている塊は1枠）。囲んだあとは移動・調整へ戻す
- 使い方を「自動分割／範囲を調整／分割結果／困ったとき」のタブに変更。作業画面のヘッダーは「？→設定」の2つ。方式変更は分割設定の左下FAB。番号・背景・元画像は結果／プレビューでスクロール追従
- 「範囲を調整」後のプレビュー(PreviewScreen)を、保存完了と同じ高解像度 PNG + ImagePreviewModal（ピンチズーム・左右送り）に統一。背景色切替と番号の出し分けも結果画面に揃えた (53cd12e)
- 画面下のバナーを固定320×50からウィンドウ幅のアンカー型アダプティブに変更。頼む幅と枠の幅を揃え、以前の文字切れ（サイズ不一致）を避ける。更新間隔はアプリでは持たず AdMob の自動更新に任せる (563095c)
- 保存成功直後にインタースティシャルを表示する。自動保存と範囲調整後保存の2経路。セッション再開の done では出さない。開発はテストID、本番は iOS/Android それぞれのユニット (07f50cc)
- 起動時と設定のバージョン行から、版ごとの更新内容シートを見られるようにした。初回オンボ完了時は今の版を既読にして出さない (417547e)
- 設定の「このアプリ」からサポートページを開けるようにし、各項目とセクション見出しにアイコンを付けた (3abcfd1)

### 修正

- 拡大プレビューでズームしたまま矢印／スワイプでページ移動すると、前の画像の拡大が残って次の画像に重なる不具合を修正。あわせて横スワイプがピンチを奪って拡大しづらかった操作も直した (53cd12e)
- 日本語ロケールでアプリ名（ホーム画面・共有シート）が英語「Sticker Cutout」のまま表示されていた不具合を修正 (3652ac9)
- Vision失敗時に色ベースへフォールバックしても既定値が更新されず、edits未保存の状態で再度Visionが実行され同じ理由で失敗し続める不具合を修正 (a1bd795)
- 背景除去方式の選択シートで「キャンセル」を押しても既定値のまま処理が進んでしまい、キャンセルの意味を成していなかった不具合を修正。キャンセル時は本当に処理を中断するように (583e39c)
- アプリアイコンの説明が、廃止済みの時間帯連動のまま残っていたのを修正。保存済みの `auto` は Day に寄せる (3abcfd1)
- 1.2 で追加した `@six33/react-native-bg-removal` がアプリ内ライセンス一覧に無かったので追加した (9ac3441)
