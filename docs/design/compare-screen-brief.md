# デザイン依頼: 「背景を消す」画面（比較＋背景の仕上げ）

## アプリについて

- アプリ名: スタンプ抜き（英語名: Sticker Cutout）。iOS / Android のスマホアプリ
- できること: LINE スタンプのように絵が並んだ画像から背景を消し、1つずつ切り分けて保存する
- 使う人: 若い人だけでなく、**祖父母世代**も使っている。透過画像や市松模様（グレーと白のチェック柄）を見慣れていない

## 解決したい問題

1. **背景が消えたことが伝わらない**: 背景を消した直後、消えた部分は市松模様で表示される。祖父母世代には「背景が消えた（透明になった）」ことが伝わっていなかった。今は「背景を透明にしました」というトーストを数秒出すだけなので、見逃すと市松模様の意味が分からないまま先へ進んでしまう
2. **1つの画面にやることが多すぎる**: 今の「分割設定」画面には、背景を消す道具（スポイト、取り消し、消し方の切り替え）と、分割する道具（行数・列数、線の移動）が同居している。どちらの作業をしているのかが分かりにくい

## 作ってほしい画面

背景を消し終えたら、**元の画像と消した後の画像を比べて、必要なら背景を仕上げる画面**を1枚挟む。今「分割設定」画面にある背景の道具は、すべてこの画面に移す。分割設定画面は分割だけを行う画面にする。

### 画面の流れ

```
画像を選ぶ → 背景を自動で消す（処理中）→ 【この画面】→ 分割設定画面
                                         ↑              │
                                         └── 戻る ──────┘
```

- 背景を消し終えるたびに、毎回出す
- 分割設定画面の「戻る」で、この画面に戻ってこられる（分割中に「背景が残っている」と気づいたら、戻って直せる）
- この画面の「戻る」はホームへ（画像の選び直し）

### 画面に必要なもの

**主役（いちばん目立たせる）**

1. **見出し**: 背景を消したことがひと目で分かる言葉（例:「背景を消しました」）
2. **元の画像と、消した後の画像の比較**: 見せ方を 2〜3 案ほしい（下の「比べ方の案」を参照）
3. **市松模様の説明**: 「チェック柄のところは透明（何もない）部分です」のように、市松模様の意味を短く説明する
4. **次へ進むボタン（メイン）**: 分割設定画面へ進む

**脇役（うまく消えていなかったときに使う。主役の邪魔をしない置き方にしてほしい）**

5. **自動で消す強さ**: スライダー。「弱い／ふつう／強い」のように3段の目盛りがある。強くするほど、背景に近い色まで広く消す。動かすと、その強さで消し直す
   - 消し方が「被写体検出」のときは、この強さは結果に影響しない。そのときはスライダーを出さないか、押せない見た目にする
6. **スポイト（タップで消す）**: オンにしてから画像をタップすると、その色の背景が消える。自動で消しきれなかった背景（枠や、絵に囲まれた内側など）を消すための道具
7. **取り消し／やり直し／最初に戻す**: スポイトで消した操作を1つ戻す・進める・全部戻す。今は3つのアイコンボタン（↶ ↷ ↻）
8. **消し方を変える**: 「色ベース」と「被写体検出（AIで絵を見分ける）」を切り替える。今は青い丸ボタン（✨アイコン）。変えると、スポイトで消した操作は消えて最初から消し直す。※ 被写体検出に対応している端末でだけ出す

### 比べ方の案（いずれかでも、別の案でもよい）

- **A. 上下（または左右）に並べる**: 「前」「後」のラベル付き。いちばん分かりやすいが、1枚ずつが小さくなる。スポイトで画像をタップするときにも小さくて押しにくい
- **B. スライダーで重ねて比べる**: 1枚の画像の上で、つまみを左右に動かすと前後が切り替わる。大きく見られるが、操作に気づかない人がいるかもしれない
- **C. 押している間だけ元の画像を出す**: 「前を見る」ボタンを押している間だけ元の画像を出す。画像を大きく使えるので、スポイトとの相性がよい
- **D. 自動で切り替わるアニメーション**: 画面を開くと、元の画像から背景がスッと消えていく様子を1回見せる。何が起きたかが直感的に伝わる。C と組み合わせてもよい

祖父母世代にいちばん伝わる案を1つおすすめしてほしい。スポイトで画像をタップする操作と両立できることも考えてほしい。

## 守ってほしい条件

### 見た目（今のアプリに合わせる）

- iOS の標準アプリ風（Human Interface Guidelines に近い）
- 色:
  - 背景 `#F2F2F7`（薄いグレー）
  - カード `#FFFFFF`
  - メインの色 `#007AFF`（青。メインボタンなど）
  - 本文 `#000000`、補足の文字 `#8E8E93`
  - 区切り線 `#C7C7CC`
  - 押せないもの・薄い塗り `#E5E5EA`
- 角丸: ボタン 12、カード 16
- 余白: 4 の倍数（8 / 12 / 16 / 24 / 32）
- メインボタンは画面下部の青い大きなボタン（横幅いっぱい、白文字）。分割設定画面の「この行数で分割」と同じ形
- ヘッダーは今の画面と同じ（左に「‹ 戻る」、中央にタイトル、右に ？（使い方）と ⚙（設定））
- アイコンは Material Icons

### 祖父母世代への配慮

- 文字は大きめ（本文 17pt 以上）
- ボタンは押しやすい大きさ（高さ 44pt 以上）
- 色だけで区別しない（「前」「後」は文字のラベルでも示す）
- 専門用語を使わない（「透過」「アルファ」「許容値」などは使わず、「透明」「何もない」「強さ」など）
- 脇役の道具が多いので、最初は見出し・比較・「次へ」だけが目に入るようにしたい（例: 脇役は「うまく消えていないときは」の下にまとめる、など）

### 画像について

- 画像は横長・縦長・正方形のどれもありうる（スタンプのシートは縦長が多い）
- 消した後の画像の下地は、設定によって「市松模様／白／黒」のどれかになる。基本は市松模様で考えてよい

### 言語

- 日本語と英語の両方に対応する。英語は文が長くなりやすいので、改行されても崩れないようにしてほしい

### 画面サイズ

- スマホの縦向き。幅 375〜430pt くらい

## 参考: 今の分割設定画面（背景の道具を移したあと）

背景の道具がなくなったあとの分割設定画面には、次のものだけが残る。

- 「自動分割／範囲を調整」の切り替え
- 画像と分割線（線をドラッグで動かせる）
- 行数・列数、「線の位置をリセット」、「分割しない」
- 「この行数で分割」ボタン

## ほしいもの

- 比べ方の案ごとのモックアップ（2〜3 案）と、おすすめの案
- おすすめの案について:
  - 日本語版と英語版
  - 脇役の道具を閉じている状態と、開いている状態
  - スポイトがオンの状態
  - 消し方が「被写体検出」のとき（強さのスライダーがない、または押せない）
  - 「消し方を変える」がない端末のとき
