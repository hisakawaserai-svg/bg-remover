# デザイン依頼: 「背景を消しました」比較画面

## アプリについて

- アプリ名: スタンプ抜き（英語名: Sticker Cutout）。iOS / Android のスマホアプリ
- できること: LINE スタンプのように絵が並んだ画像から背景を消し、1つずつ切り分けて保存する
- 使う人: 若い人だけでなく、**祖父母世代**も使っている。透過画像や市松模様（グレーと白のチェック柄）を見慣れていない

## 解決したい問題

背景を消した直後の画面では、消えた部分が市松模様で表示される。しかし、祖父母世代には「背景が消えた（透明になった）」ことが伝わっていなかった。

今は「背景を透明にしました」というトーストを数秒出しているだけなので、見逃すと市松模様の意味が分からないまま先へ進んでしまう。

## 作ってほしい画面

背景を消し終えたら、**元の画像と、背景を消した後の画像を比べられる画面**を1枚挟む。

### 画面の流れ

```
画像を選ぶ → 背景を自動で消す（処理中）→ 【この画面】→ 分割設定画面
```

- 背景を消し終えるたびに、毎回出す
- 「戻る」で分割設定画面から戻ってきたときは出さない
- 設定画面に「この画面を出さない」というスイッチを付ける予定（この画面の中に「次から表示しない」を置くかどうかも提案してほしい）

### 画面に必要なもの

1. **見出し**: 背景を消したことがひと目で分かる言葉（例:「背景を消しました」）
2. **元の画像と、消した後の画像の比較**: 見せ方を 2〜3 案ほしい（下の「比べ方の案」を参照）
3. **市松模様の説明**: 「チェック柄のところは透明（何もない）部分です」のように、市松模様の意味を短く説明する
4. **次へ進むボタン（メイン）**: 分割設定画面へ進む
5. **うまく消えていなかったときの逃げ道（サブ）**: 例:「うまく消えていない」→ 背景の消し方（方式）を変える。※ この方式の切り替えは、対応している端末でだけ出す
6. **戻る**: ヘッダー左。ホームへ戻る（画像の選び直し）

### 比べ方の案（いずれかでも、別の案でもよい）

- **A. 上下（または左右）に並べる**: 「前」「後」のラベル付き。いちばん分かりやすいが、1枚ずつが小さくなる
- **B. スライダーで重ねて比べる**: 1枚の画像の上で、つまみを左右に動かすと前後が切り替わる。大きく見られるが、操作に気づかない人がいるかもしれない
- **C. タップ（または長押し）で切り替える**: 「前を見る」ボタンを押している間だけ元の画像を出す
- **D. 自動で切り替わるアニメーション**: 画面を開くと、元の画像から背景がスッと消えていく様子を1回見せる。何が起きたかが直感的に伝わる

祖父母世代にいちばん伝わる案を1つおすすめしてほしい。

## 守ってほしい条件

### 見た目（今のアプリに合わせる）

- iOS の標準アプリ風（Human Interface Guidelines に近い）
- 色:
  - 背景 `#F2F2F7`（薄いグレー）
  - カード `#FFFFFF`
  - メインの色 `#007AFF`（青。メインボタンなど）
  - 本文 `#000000`、補足の文字 `#8E8E93`
  - 区切り線 `#C7C7CC`
- 角丸: ボタン 12、カード 16
- 余白: 4 の倍数（8 / 12 / 16 / 24 / 32）
- メインボタンは画面下部の青い大きなボタン（横幅いっぱい、白文字）。分割設定画面の「この行数で分割」と同じ形
- アイコンは Material Icons

### 祖父母世代への配慮

- 文字は大きめ（本文 17pt 以上）
- ボタンは押しやすい大きさ（高さ 44pt 以上）
- 色だけで区別しない（「前」「後」は文字のラベルでも示す）
- 専門用語を使わない（「透過」「アルファ」などは使わず、「透明」「何もない」など）

### 画像について

- 画像は横長・縦長・正方形のどれもありうる（スタンプのシートは縦長が多い）
- 消した後の画像の下地は、設定によって「市松模様／白／黒」のどれかになる。基本は市松模様で考えてよい

### 言語

- 日本語と英語の両方に対応する。英語は文が長くなりやすいので、改行されても崩れないようにしてほしい

### 画面サイズ

- スマホの縦向き。幅 375〜430pt くらい

## ほしいもの

- 比べ方の案ごとのモックアップ（2〜3 案）と、おすすめの案
- おすすめの案について、日本語版と英語版
- 「うまく消えていない」の逃げ道がある場合とない場合（方式の切り替えに対応していない端末）
